Creating lists using HTML.

Types of lists :

  1. Ordered Lists
  2. Unordered lists
  3. Descriptive lists

This is an Example of ordered lists :

It is used when we need the items to be maintained in an order.

  1. Items 1
  2. Items 2
  3. Items 3
  4. Items 4

This is an Example of Unordered List :

it is used when we have no demand for the order in the list items.

  • item 1
  • item 2
  • item 3
  • item 4

This is an Example of Descriptive List :

It is used to describe terms and their descriptions.

Nested Lists.

This is used when we a deeper nest in the lists.

The nested list can be either Unordered list or Ordered list or even a Descriptive List


for this ex we are taking ordered list which contains unordered list.

  1. Nested Order List.
    1. Nested Ordered list item 1
    2. Nested Ordered list item 2
    3. Nested Ordered list item 3
  2. Nested Unordered List.
    • Nested Unordered list item 1
    • Nested Unordered list item 2
    • Nested Unordered list item 3
  3. Nested Descriptive List.
    Ordered list
